# Felipe Espinosa Orjuela

AI/ML Engineer in Paris · LLM agents, generative models and evaluation · M.Sc. AI, Université Paris-Saclay

### Selected work

- **Text-to-SQL agent – Capital Fund Management (2025).** LangGraph agent with 7 tools that answers analysts' questions over an internal Oracle database: 87.5% accuracy on a 48-question benchmark I built, about 20× cheaper per query than o3 at similar accuracy. Code is internal; [internship report (PDF)](https://github.com/Pipe1213/Pipe1213/raw/main/CFM_internship_report.pdf).
- **First text-to-speech system for Walloon – LISN, CNRS (2024).** VITS trained on 18 and 156 minutes of speech; 4.22/5 MOS with 23 native listeners. First-author paper, SSW 2025. [Code](https://github.com/lisn-speech-synthesis/Walloon-Synthesis-VITS) · [Paper](https://doi.org/10.21437/SSW.2025-29) · [Demo](https://huggingface.co/spaces/Pipe1213/VITS_Walloon_Graphemes)
- **AskData (in progress).** Ask a PostgreSQL database questions in plain English: schema retrieval, planner-guided SQL, read-only validation. FastAPI, Next.js. [Repo](https://github.com/Pipe1213/AskData)
- **Synthetic French NER dataset for clinical trials (2024, team of 3).** Translated English annotations, fine-tuned XLM-RoBERTa, released a 12,423-row dataset. [Repo](https://github.com/jlopetegui98/Creation-of-a-synthetic-dataset-for-French-NER-in-clinical-trial-texts)

**Now:** research collaborator at Universidad Tecnológica de Bolívar, lead author of a paper on cross-lingual embeddings (under review).

**Stack:** Python · PyTorch · Hugging Face Transformers · LangGraph · FastAPI · PostgreSQL · Docker · Git · Linux
